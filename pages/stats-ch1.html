第一章：緒論

核心觀念摘要

  • 統計學的意義：狹義指以數字表示的事實或資料；廣義則是蒐集、整理、表現、分析與解釋資料，進而做出適切決策的方法與學科。
  • 母體與樣本：母體（Population）是研究對象的全體集合，其測量數稱為「母體參數」；樣本（Sample）是從母體抽取的部分集合，其測量數稱為「樣本統計量」。
  • 敘述統計 vs 推論統計：敘述統計負責蒐集、彙整與呈現資料；推論統計則利用已知的樣本統計量去推論未知的母體參數。
  • 歸納法與演繹法：歸納法是由樣本統計量推論母體參數；演繹法則是假設母體參數已知，進而推導樣本特性。
  • 統計方法五大實施步驟：①確定問題 → ②蒐集資料 → ③審查整理呈現資料 → ④分析解釋資料 → ⑤統計推論。

關鍵專有名詞與公式重點

術語 / 概念 說明與重點
Population / Sample母體（全體集合）與樣本（抽樣所得的部分集合）。
Parameter / Statistic母體參數（描述母體特性）與樣本統計量（描述樣本特性）。
Descriptive Statistics敘述統計學，負責整理、圖表呈現與計算統計測量數。
Inferential Statistics推論統計學，利用樣本資訊對母體進行估計與檢定。
