第六章：間斷隨機變數及其常用的機率分配

核心觀念摘要

  • 間斷隨機變數與機率函數：變量個數有限或無限但可數者為間斷隨機變數；機率函數需滿足 0 ≤ f(x) ≤ 1 且總和為 1。
  • 期望值與變異數性質：E(X) = Σx·f(x)，V(X) = E(X²) − [E(X)]²；線性函數滿足 E(a+bX) = a + bE(X) 與 V(a+bX) = b²V(X)。
  • 二項機率分配（Binomial）：n 次獨立重複試行、每次僅成功（p）或失敗（q=1−p）；期望值 np、變異數 npq。
  • 泊松分配（Poisson）：衡量固定區間內稀有事件發生次數，參數為 λ，且期望值與變異數皆等於 λ；當 n 大且 p 小時可近似二項分配。
  • 超幾何分配（Hypergeometric）：有限母體（N）中「抽出不放回」抽取 n 個樣本的成功次數分配，變異數包含有限母體修正項 (N−n)/(N−1)。

關鍵專有名詞與公式重點

術語 / 概念 說明與重點
Discrete Random Variable間斷隨機變數，可能取值為有限個或可數無窮多個。
Binomial Distribution二項分配，適用於獨立重複試驗且每次只有成功/失敗兩種結果。
Poisson Distribution泊松分配，描述單位時間或空間內事件發生的次數，E(X)=V(X)=λ。
Hypergeometric Distribution超幾何分配，適用於有限母體且「抽出不放回」的抽樣情境。
