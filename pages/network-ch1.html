第一章：網路基本概念

核心觀念摘要

  • 網路的功用與規模分類：透過傳輸媒介連結裝置以分享檔案、訊息、週邊與應用程式；依範圍可分為個人網路（PAN）、區域網路（LAN，範圍小且穩定）、廣域網路（WAN，跨都市或國界）與網際網路（Internet）。
  • DoD 四層網路模型：由上而下分為應用層（Application）、傳輸層（Transport）、網路層（Network）與連結層（Link）。每層將資料加上表頭的動作稱為「封裝（Encapsulation）」。
  • OSI 七層模型與差異：將網路細分為實體、鏈結、網路、傳輸、會議、表達、應用共 7 層；相比 DoD 多了會議層與表達層，且將連結層拆分為實體層與鏈結層。
  • 四種網路拓樸（Topology）：匯流排（Bus，易碰撞且單點斷線即癱瘓）、星狀（Star，以 Switch 取代 Hub 提升效能）、環狀（Ring，依令牌 Token 傳遞不碰撞）與網狀（Mesh，具容錯能力但佈線成本高）。
  • SDN 軟體定義網路：將控制層與資料層分離，由 SDN 控制器透過 Northbound / Southbound API 統一管理網路架構並規劃最佳路徑。

關鍵英文專有名詞

英文術語 中文說明與重點
DoD Model 美國國防部網路模型，將網際網路分工為連結、網路、傳輸、應用 4 層。
OSI Model 開放系統互連模型（Open Systems Interconnection），分為 7 層架構。
Encapsulation / Payload 封裝（加上各層表頭的動作）與資料承載（封裝前的原始資料）。
Packet / Frame 封裝後的資料稱為封包；在連結層傳送的封包則稱為訊框。
Fault Tolerance 容錯能力，網狀網路因擁有多條路徑而具備高度容錯特性。
SDN (Software Defined Network) 軟體定義網路，透過軟體集中控制 OSI 第 2～7 層的網路架構。
