第二章：數據通訊與傳輸媒介

核心觀念摘要

  • 實體層與訊號類型：實體層負責將資料依媒介特性轉為電流（銅線）、光（光纖）或電磁波（無線）；數位訊號狀態有限且抗雜訊能力優於連續變化的類比訊號。
  • 基頻編碼技術（Baseband）：直接改變電位高低傳遞資料，包含 NRZ、RZ、NRZI、Manchester（每個位元中間必轉態以提供同步）與 Differential Manchester（1 顛倒、0 維持前一位元變化方式）。
  • 寬頻調變技術（Broadband）：將資料加入載波（Modulation），分為控制振幅（ASK）、頻率（FSK）、相位（PSK：BPSK/DBPSK/QPSK）及結合振幅與相位的正交振幅調變（QAM）。
  • 同步、頻寬與多工存取：接收端需時脈同步以判斷位元邊界；傳輸頻寬單位為 bps，實際速率稱為 Throughput；多工分為分頻多工（FDM）與分時多工（同步 / 非同步 TDM）。
  • 有線與無線傳輸媒介：雙絞線（UTP / STP，Cat 3～Cat 8）便宜且佈線彈性高，但易受電磁干擾；光纖（SMF 單模長距離 vs MMF 多模短距離）高速且抗干擾；無線電磁波頻率越高，穿透力越低且越趨直線傳播。

關鍵英文專有名詞

英文術語 中文說明與重點
Baseband / Broadband 基頻傳輸（直接控制訊號狀態）與寬頻傳輸（控制載波狀態）。
Differential Manchester 差動式曼徹斯特編碼，自帶時脈同步且較具抗極性反轉能力。
ASK / FSK / PSK / QAM 振幅、頻率、相位偏移鍵制與正交振幅調變技術。
Throughput 流通量（傳輸效率），代表網路實際能達到的資料傳輸速率。
Multiplexing (FDM / TDM) 多工存取，包含切割頻寬的分頻多工與輪流使用時槽的分時多工。
UTP / STP 無遮蔽式雙絞線與遮蔽式雙絞線（多一層金屬遮蔽抗干擾）。
SMF / MMF 單模式光纖（長距離、效能極佳）與多模式光纖（短距離、成本較低）。
